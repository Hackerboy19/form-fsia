TL;DR

  • Lost leads

    The Bharat Couture Week form submits to save-bharat-couture-week.php, which returns 404 on the live site. Every registration from that page is being lost.

  • Mis-filed

    Celebrity PR Agency and Forever Fashion Week post to the fashion-designer save script without a type or category. India Fashion Week sends the same type code (43) as Fashion Designer, so the back office can't tell these registrations apart.

  • Silent errors

    None of the 72 pages shows server validation errors. They read $_SESSION['form_error'] but never print it. The save scripts reply with bare text such as "Name is required", which leaves users on a blank page.

  • Security

    No security headers, an insecure session cookie, a public unthrottled OTP sender, include files that can be loaded directly, no CSRF tokens, and unescaped CMS text in every page head.

  • Speed

    The ~5,000 profile pages have the same problems as the forms. They load the Tailwind CDN, the full 557 KB Lucide icon library, and 16 images that each redirect from fsia.in to www first.

  • Data

    Google Analytics is configured twice on the homepage, so homepage pageviews and bounce rate are wrong.

Keep

What's already right

Security

  • .git, .env, composer.*, *.sql and backups return 403
  • Directory listing is off (/uploads/, /cms/, /static/)
  • http → https and non-www → www 301s work
  • The Miss/Mrs India and Channel Partner save scripts reject submissions without OTP ("Verify Mobile Number First")
  • Email: SPF plus DMARC p=quarantine with strict alignment
  • No phpMyAdmin, phpinfo or server-status exposed

Platform

  • PHP 8.3 is a supported version (security fixes until end of 2027)
  • HTTP/2, gzip and Brotli are on
  • Server is fast: about 0.1 s of processing, p99 TTFB 1.06 s across 5,325 URLs
  • Real 404s for unknown URLs
  • Form pages barely shift while loading (CLS ≤ 0.01)
